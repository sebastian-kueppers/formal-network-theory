# A Formal Network Model of Co-Occurring Emotions: Analysis Code

Code and data for Kueppers, S., Auerbach, X., Lange, J. (2027). _A Formal Network Model of Co-Occurring Emotions_ 

This repository contains the formal co-occurrence model, the toy example, the empirical example (Study 2), the sensitivity analyses, and the theory comparison (IMEC) reported in the manuscript.

## Repository structure

```

model/ # cooccurrence.model() and ising_network(), version 1.1.3 (see CHANGELOG.md)
helpers/ # shared helper functions (one function per file), sourced by the scripts
toy example/ # toy example script and output
empirical example/ # study data, analysis script, and estimated networks
	simulation/ # simulations from the empirical networks (results, figures)
supplementary analyses/ # sensitivity analyses for the toy example
theory comparison/ # IMEC theory comparison

```
